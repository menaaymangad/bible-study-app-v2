# Bible School V2

Bible School V2 is the multi-church edition of the Bible School app.

This repository is a **distribution-only** repository. It hosts app releases
and download links; it does not contain application source code or
development history. Source is maintained in a private repository.

V2 is a separate app from the original Bible School (V1) and installs
alongside it.

## Download

Latest APK (always up to date):

**[Download BibleSchoolV2.apk](https://github.com/menaaymangad/bible-study-app-v2/releases/latest/download/BibleSchoolV2.apk)**

Or grab a specific version from the [Releases](https://github.com/menaaymangad/bible-study-app-v2/releases) page.

### Installing on Android

1. Download `BibleSchoolV2.apk` using the link above.
2. If prompted, allow installation from this source in your device settings.
3. Open the downloaded file to install.
